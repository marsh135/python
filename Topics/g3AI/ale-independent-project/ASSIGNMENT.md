# Your assignment

Train an AI to play an Atari game other than Breakout. Use our class code as your starting point.

## Checklist

- [ ] I chose a different game.
- [ ] My `train.py` runs and saves a model.
- [ ] My `watch.py` loads that model and opens a game window.
- [ ] The AI plays without me controlling it.
- [ ] Watching the model does not start training again.
- [ ] I included my saved model and all the code needed to watch it.
- [ ] I completed `REPORT.md`.

## How you will be graded

| Requirement | Points |
| --- | ---: |
| Training code works and saves a model | 40 |
| Viewing code loads the saved model and shows it playing | 40 |
| Short answers and complete submission | 20 |

You are graded on getting the project working and explaining what you did. A high game score is not required.
